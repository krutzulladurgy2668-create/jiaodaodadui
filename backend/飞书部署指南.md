# 飞书审批部署指南

## 第一步：上传文件到服务器

将 `backend` 文件夹上传到服务器的 `/www/wwwroot/jiaodao.fun/` 目录

## 第二步：在宝塔面板安装和启动

1. 打开宝塔面板 → 软件商店
2. 安装「PM2管理器」

## 第三步：安装依赖和启动

在服务器终端运行：

```bash
cd /www/wwwroot/jiaodao.fun/backend
npm install --production
```

## 第四步：在PM2管理器中添加项目

1. 宝塔面板 → PM2管理器
2. 点击「+ 添加项目」
3. 启动文件选择：`/www/wwwroot/jiaodao.fun/backend/server.js`
4. 项目名称填：`jiaoda-backend`
5. 点击「提交」

## 第五步：配置反向代理

1. 宝塔面板 → 网站 → jiaodao.fun → 设置
2. 点击「反向代理」→「添加反向代理」
3. 配置：
   - 代理名称：`api`
   - 目标URL：`http://127.0.0.1:3000`
4. 点击「提交」

5. 找到刚添加的反向代理，点击「配置」→「高级配置」
6. 把下面的内容完整粘贴进去：

```nginx
location /api/ {
    proxy_pass http://127.0.0.1:3000;
    proxy_set_header Host $host;
    proxy_set_header X-Real-IP $remote_addr;
    proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
    proxy_http_version 1.1;
    proxy_set_header Upgrade $http_upgrade;
    proxy_set_header Connection "upgrade";
}

location /feishu/ {
    proxy_pass http://127.0.0.1:3000;
    proxy_set_header Host $host;
    proxy_set_header X-Real-IP $remote_addr;
    proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
    proxy_http_version 1.1;
    proxy_set_header Upgrade $http_upgrade;
    proxy_set_header Connection "upgrade";
}
```

7. 保存

## 第六步：在飞书开放平台配置

### 6.1 创建应用

1. 打开 https://open.feishu.cn/
2. 登录并创建企业自建应用
3. 应用名称：「教导大队新闻审批」

### 6.2 添加审批应用能力

1. 在应用功能中找到「审批」
2. 创建审批模板：「新闻发布审批」
3. 添加以下字段：
   - 字段类型：单行输入 → 标签：「新闻标题」→ 设为必填
   - 字段类型：多行输入 → 标签：「新闻简介」
   - 字段类型：多行输入 → 标签：「新闻正文」→ 设为必填
   - 字段类型：日期选择 → 标签：「发布日期」
   - 字段类型：单行输入 → 标签：「发布部门」

### 6.3 配置事件订阅

1. 在应用功能中找到「事件订阅」
2. 添加订阅：
   - 请求地址：`https://jiaodao.fun/feishu/callback`
3. 订阅事件：「审批实例状态变更」

## 第七步：测试

1. 在飞书中发起审批申请
2. 填写新闻信息并提交
3. 审批人审批通过
4. 查看PM2日志，确认收到回调
5. 查看网站，确认新闻已更新

## API说明

- GET https://jiaodao.fun/api/health - 健康检查
- GET https://jiaodao.fun/api/news - 获取新闻列表
- POST https://jiaodao.fun/api/news - 发布新闻
