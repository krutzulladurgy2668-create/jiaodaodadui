## 🚀 快速部署

### 第一步：上传文件

将 `backend` 目录上传到服务器，例如：
```
/var/www/html/backend
```

### 第二步：安装依赖

```bash
cd /var/www/html/backend
npm install --production
```

### 第三步：启动服务

```bash
# 安装PM2进程管理器
npm install -g pm2

# 启动服务
pm2 start server.js --name jiaoda-backend

# 设置开机自启
pm2 save
pm2 startup

# 查看服务状态
pm2 status
pm2 logs jiaoda-backend
```

### 第四步：测试服务

```bash
# 本地测试
curl http://localhost:3000/api/health

# 预期输出：
# {"status":"ok","message":"教导大队后端服务正常运行"}
```

## 🔧 Nginx配置

### 配置文件

创建或编辑 Nginx 配置文件：

```nginx
server {
    listen 80;
    server_name jiaodaodadui.com.cn; # 替换为您的域名

    # 前端静态文件
    location / {
        root /var/www/html;
        index index.html index.htm;
        try_files $uri $uri/ /index.html;
    }

    # 后端API代理
    location /api/ {
        proxy_pass http://127.0.0.1:3000;
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection 'upgrade';
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
        proxy_cache_bypass $http_upgrade;
        proxy_connect_timeout 60s;
        proxy_send_timeout 60s;
        proxy_read_timeout 60s;
    }
}
```

### 应用配置

```bash
# 测试配置
sudo nginx -t

# 重启Nginx
sudo systemctl restart nginx
```

## 🌐 前端集成

### 方案一：渐进式（推荐）

1. 将 `api.js` 和 `data-loader.js` 复制到网站目录
2. 在 `website.html` 的 `<head>` 中添加：
   ```html
   <script src="api.js"></script>
   <script src="data-loader.js"></script>
   ```
3. 在 `data-loader.js` 中将 `USE_BACKEND_API` 设置为 `false`（先用本地模式）
4. 测试没问题后，再改为 `true`

### 方案二：直接使用后端

修改前端代码中的数据加载逻辑，直接调用API。

## 📊 API使用示例

### 获取所有新闻
```javascript
const result = await window.JiaoDaAPI.NewsAPI.getAll();
if (result.success) {
  console.log('新闻数据:', result.data);
}
```

### 创建新闻
```javascript
const newsItem = {
  title: '新闻标题',
  desc: '新闻简介',
  date: '2026-05-20',
  author: '宣传部',
  content: '新闻内容'
};
const result = await window.JiaoDaAPI.NewsAPI.create(newsItem);
```

### 检查服务状态
```javascript
const result = await window.JiaoDaAPI.checkHealth();
console.log('服务状态:', result);
```

## 🔍 常见问题

### Q: 端口被占用怎么办？

A: 修改 `server.js` 中的 `PORT` 或使用环境变量：
```bash
PORT=3001 pm2 restart jiaoda-backend
```

### Q: 如何重启服务？

```bash
pm2 restart jiaoda-backend
```

### Q: 如何查看日志？

```bash
# 实时日志
pm2 logs jiaoda-backend

# 最近100行
pm2 logs jiaoda-backend --lines 100
```

### Q: 数据存储在哪里？

A: 在 `backend/data/` 目录下，以JSON文件格式存储。

### Q: 如何备份数据？

```bash
cp -r /var/www/html/backend/data /var/www/html/backup/data_$(date +%Y%m%d)
```
