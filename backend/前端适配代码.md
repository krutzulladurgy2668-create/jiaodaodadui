# 🌐 前端适配代码

## 📋 说明

这份文档说明如何修改前端以支持从后端API加载新闻。

---

## 📁 文件修改

### 1. 复制文件

将后端目录中的：
- `api.js`
- `data-loader.js`

复制到网站根目录 `/www/wwwroot/jiaodaodadui.com.cn/`

### 2. 修改website.html

在website.htmlhead标签内，在 `<head>标签内添加：

```html
<script src="api.js"></script>
<script src="data-loader.js"></script>
```

---

## 🔄 数据加载方式

### 修改data-loader.js

在文件开头找到：

```javascript
const USE_BACKEND_API = false;
```

修改为：

```javascript
const USE_BACKEND_API = true;
```

---

## 📊 新闻加载函数

### 加载新闻数据

找到 `loadNewsData` 函数：

```javascript
async function loadNewsData() {
  if (window.USE_BACKEND_API) {
    try {
      const result = await window.JiaoDaAPI.NewsAPI.getAll();
      if (result && result.success) {
        return result.data;
      }
    } catch (e) {
      console.error('从后端加载新闻失败:', e);
    }
  }
  
  const saved = localStorage.getItem('newsData');
  if (saved) {
    try {
      let data = JSON.parse(saved);
      data = data.map(item => {
        const { img, imgs, ...cleanItem } = item;
        return cleanItem;
      });
      return data;
    } catch (e) {
      return getDefaultNews();
    }
  }
  return getDefaultNews();
}
```

### 保存新闻数据

```javascript
async function saveNewsData(news) {
  if (window.USE_BACKEND_API) {
    try {
      // 先尝试更新本地缓存
      localStorage.setItem('newsData', JSON.stringify(news));
      
      // TODO: 根据操作类型调用API
      console.log('新闻数据已保存到本地');
    } catch (e) {
      console.error('保存新闻失败:', e);
    }
  } else {
    localStorage.setItem('newsData', JSON.stringify(news));
  }
}
```

## ✅ 完整替换方案

或者可以创建一个单独的js文件替换原有逻辑，保持功能一样，只需要：

1. 复制 api.js 和 data-loader.js
2. 在head中引入
3. 修改 USE_BACKEND_API = true
4. 替换loadNewsData/saveNewsData函数

## 🔍 验证检查

打开浏览器控制台，查看：

1. 打开网站
2. 打开开发者工具（F12）
3. 查看Console标签
