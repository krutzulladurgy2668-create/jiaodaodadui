## 📁 第一步：文件准备

### 需要上传的文件

将以下文件上传到服务器的 `/www/wwwroot/jiaodao.fun/backend/` 目录：

- `server.js` - 后端服务主文件
- `package.json` - 项目依赖配置
- `.env` - 环境变量配置（需要修改
- `.env.example` - 环境变量示例

---

## 🛠️ 第二步：宝塔面板配置

### 2.1 安装PM2管理器

1. 打开宝塔面板 → 软件商店
2. 搜索 "PM2管理器"
3. 点击安装

### 2.2 安装Node.js版本管理器

在PM2管理器中：
1. 点击「版本管理」
2. 安装 Node 16.x 或更高版本

---

## 🚀 第三步：部署后端服务

### 3.1 添加Node.js项目

1. PM2管理器 → 「项目列表
2. 点击「+ 添加项目」
3. 填写信息：
   - 项目名称：`jiaoda-backend`
   - 启动文件：`/www/wwwroot/jiaodao.fun/backend/server.js
   - 项目目录：`/www/wwwroot/jiaodao.fun/backend/`
   - 启动方式：`Node`
   - Node版本：选择刚才安装的版本
4. 点击「提交」

### 3.2 配置环境变量

1. 在项目列表中找到 `jiaoda-backend`
2. 点击「设置」→ 「环境变量」
3. 添加以下变量：

```env
PORT=3000
DINGTALK_ENABLED=true
DINGTALK_TOKEN=（从钉钉开发者后台获取）
DINGTALK_AES_KEY=（从钉钉开发者后台获取）
DINGTALK_APP_KEY=（从钉钉开发者后台获取）
DINGTALK_APP_SECRET=（从钉钉开发者后台获取）
```

### 3.3 启动服务

1. 在PM2管理器中找到 `jiaoda-backend`
2. 点击「启动」
3. 查看状态显示「运行中」
4. 点击「日志」查看是否有运行日志

---

## 🔌 第四步：配置反向代理

### 4.1 添加反向代理

1. 网站 → `jiaodao.fun` → 设置 → 反向代理
2. 点击「+ 添加反向代理」
3. 填写信息：
   - 代理名称：`dingtalk-api`
   - 目标URL：`http://127.0.0.1:3000`
   - 发送域名：`$host`
4. 点击「提交」

### 4.2 修改配置

1. 找到刚才添加的反向代理 → 配置
2. 点击「配置文件」
3. 修改为以下内容：

```nginx
location /api/ {
    proxy_pass http://127.0.0.1:3000;
    proxy_set_header Host $host;
    proxy_set_header X-Real-IP $remote_addr;
    proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
    proxy_set_header REMOTE-HOST $remote_addr;
    proxy_set_header X-Forwarded-Proto $scheme;
    
    proxy_http_version 1.1;
    proxy_set_header Upgrade $http_upgrade;
    proxy_set_header Connection "upgrade";
    
    proxy_connect_timeout 60s;
    proxy_send_timeout 60s;
    proxy_read_timeout 60s;
}

location /dingtalk/ {
    proxy_pass http://127.0.0.1:3000;
    proxy_set_header Host $host;
    proxy_set_header X-Real-IP $remote_addr;
    proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
    proxy_set_header REMOTE-HOST $remote_addr;
    proxy_set_header X-Forwarded-Proto $scheme;
    
    proxy_http_version 1.1;
    proxy_set_header Upgrade $http_upgrade;
    proxy_set_header Connection "upgrade";
    
    proxy_connect_timeout 60s;
    proxy_send_timeout 60s;
    proxy_read_timeout 60s;
}
```

4. 保存配置

## 🔔 第五步：配置钉钉审批

### 5.1 创建钉钉审批模板

1. 登录钉钉开放平台：https://open-dev.dingtalk.com/
2. 进入应用开发 → 您的应用
3. 点击「应用功能」→ 「审批」
4. 创建新的审批模板「新闻发布审批」

### 5.2 设计审批表单

添加以下表单字段：

| 字段名称 | 字段类型 | 必填 | 说明 |
|---------|---------|-----|------|
| 新闻标题 | 单行文本 | ✅ | 必填 |
| 新闻简介 | 多行文本 | ❌ | 选填 |
| 新闻正文 | 多行文本 | ✅ | 必填 |
| 发布日期 | 日期选择 | ❌ | 选填 |
| 发布部门 | 单行文本 | ❌ | 选填 |

### 5.3 配置审批流程

设计审批流程：
1. 发起人 → 审批人（宣传部）→ 审批人（夏建平）

### 5.4 配置事件订阅

1. 应用管理 → 「事件与推送」
2. 点击「事件订阅」
3. 选择「HTTP推送」
4. 填写信息：
   - 订阅方式：HTTP推送
   - 订阅地址：`https://jiaodao.fun/dingtalk/callback`
   - Token：（您的token
   - EncodingAESKey：（您的AES密钥）
5. 选择订阅事件：审批任务状态变更事件
6. 保存并启用

const USE_BACKEND_API = true;  // 改为 true 使用后端API

## 🔧 常见问题

### 问题1：PM2服务无法启动

- 检查端口3000是否被占用
- 检查Node版本是否正确
- 查看PM2日志

### 问题2：钉钉回调失败

- 检查回调地址是否正确
- 检查Token和AES Key是否正确
- 检查事件是否订阅成功

### 问题3：新闻不显示

- 检查前端代码是否正确修改
- 检查data目录是否有news.json
- 检查文件权限是否正确
